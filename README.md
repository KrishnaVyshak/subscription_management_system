# Subscription Management System

The React frontend is in `frontend/` and uses Vite.

From that directory, run:

- `npm install` to install dependencies.
- `npm run dev` (or `npm start`) to start the development server.
- `npm test` to run tests once, or `npm run test:watch` for watch mode.
- `npm run build` to create a production build in `frontend/dist/`.
- `npm run preview` to preview the production build locally.
